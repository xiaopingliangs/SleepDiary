ProtocolInputCapture 在同一 Room 事务读取指定日历日期范围（含首尾）的全部原始日记字段、全部 SafetyAssessment/SafetyAnswer 和实际 AppState。AppState 不存在时保留不存在，不合成为默认值。不读取个人笔记、不分析 comment，不重算安全结论、TST/SE 或治疗指标。

RAW_INPUT_CAPTURE_1 使用固定字段顺序、按 ID 排序的集合、UTF-8、显式 null 标记和大端四字节长度/整数、单字节布尔编码。范围和编码版本进入哈希；每次捕获 UUID/时间不进入内容哈希。原字符串不 trim、不改 Unicode、不补秒，不把原始 detailJson 解析再改写。损坏 Unicode 拒绝，不能静默替换字符后哈希。此二进制内部格式不是 JSON 备份，也不是对外交换标准。

CapturedProtocolInput 防御性复制输入和输出字节数组；随后日记编辑或调用方修改数组，不会改变已捕获内容。哈希只证明内容一致性，不证明医学有效或来源可信。

本轮没有磁盘快照表、解码/重放器、restore generation、持久化安全水位或计划提交服务；不能把本轮描述为已完成治疗持久化。下一步需形成这些对象的版本化增量合同，扩展 Room 和完整备份，并将快照与决策审计原子写入。旧 UUID 无法补造过去原始值这一局限仍保留。捕获事务完成后的编辑仍须由提交事务重新核对输入，不能仅凭已有快照放行。
