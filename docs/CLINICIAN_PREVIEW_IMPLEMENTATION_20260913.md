# 就诊摘要：本机预览与已获批准的 TXT 导出

2026-09-13，完整版开发中的一个已实现模块切片，不是完整版完成报告。

## 最初本机预览阶段（历史）

设置 → 就诊摘要 → 选择日期范围与信息 → 生成本机预览 → 返回设置。

- ClinicianSummaryService 在一个 Room 只读事务中捕获日记及用户主动选择的当前 Safety 数据；不修改数据库。
- 按起止日期包含两端，显示记录数与日历天数，缺日不作为零。
- 默认不含自由备注和 Safety；两项独立勾选，未勾选的数据不进入摘要文本。
- Safety 显示为自报，保留 DRAFT、原始分流标记和版本，不把无记录解释为安全、不作诊断。
- 显示八个日记构念、记录时区、UUID、版本和最后修改时间；不计算 TST/SE 或治疗效果。
- 当前不存在已启用治疗，因此不捏造计划、治疗周或窗口。
- 修改日期/选择会使旧预览失效。预览存于页面 ViewModel，不作为新业务数据持久化；进程重建需重新生成。不将大段敏感文本塞入 SavedState。
- 只提供本机显示，没有文件写入、复制、Sharesheet 或后台上传。

## 最初被审批拦截的内容与后续批准方案

自动审批拒绝了初版补丁中的新 TXT 导出链路，理由是其可能包含自由备注与安全问询等敏感健康信息，认为具体负载和目的地尚未明确授权。初版补丁未落盘，没有实际导出数据；当前安全替代版本完全移除了该出口。

用户随后明确回复“批准，继续”。以下范围现已获批准并实现，不再作为待确认项：

1. 仅把本页已经生成并展示的那一份摘要导出为 UTF-8 明文 TXT，不生成其他未预览数据。
2. 日期范围内的八个原始构念、时区及追溯信息包含在内；自由备注与当前 Safety 分别由用户显式勾选，默认均关闭。
3. 用户点击“导出这份预览”后，通过 Android 系统文件创建器主动选择目的地；不预设公共路径，不自动发送给任何医生或第三方服务。
4. 显示明文和敏感内容提醒；取消不写出，写入或关闭失败不报告成功；预览因进程重建丢失时拒绝导出并要求重新生成。
5. 不改变现有 PNG 白名单、CSV、完整 JSON 备份定义，不新增联网或存储权限。
6. 开发自动化测试只用合成内存数据，不拿用户真机数据库实际外传。

## TXT 导出实现与实际验证

SummaryTextWriter 仅接收锁定的预览字符串并写 UTF-8；只有 use 成功关闭流才返回成功。ClinicianPreviewModel 在用户确认时锁定预览，SAF 返回不再次读取数据库；pendingExport 不写 SavedState/Room，进程重建后若丢失该预览，拒绝打开输出流。选文件期间禁用选择变更和重复导出；执行写出由页面 ViewModel scope 管理。

新增 13 项自动化测试，包括：精确 UTF-8 字节、备注/Safety 独立选择、预览后的数据库修改不进入导出、取消提示/文件选择、写入及关闭失败、丢失预览、重复请求、保存状态恢复后使用同一预览且不重开选择器。
